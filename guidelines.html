Store Guidelines

Back to the Store

Everything in the 5x1 Store is reviewed by a person before it is added. These guidelines say what we look for, so your theme or skill gets in quickly and owners can trust what they install on their Jibo.

Submitting

  • Open a pull request on JRG5x1/store that adds your public repository to manifest.json.
  • The repository needs a manifest.json (skills can use package.json), a README.md that says what it does, and an optional banner.png. Skills also need an icon.png.
  • The installable ZIP must be 32 MB or smaller.
  • Updates go live from your repository, so every update must follow these guidelines too.

Safety and privacy

  • No malware, hidden behaviour, tracking, ads or crypto mining. Code may be minified only if the readable source is in the repository.
  • Ask only for the permissions your skill really uses, and say in the README why it needs each one. Owners see them before installing.
  • Use the microphone and cameras only while your skill is open, unless it says otherwise and has the background permission.
  • Do not send recordings, photos, names or anything from Jibo's memory off the robot without saying so clearly in the README and in the skill.
  • run-programs and the Jibo file permissions give a skill a lot of power. Skills asking for them get a closer review and need a clear reason.

Quality

  • It must install, open, close and uninstall cleanly without breaking Jibo or other skills.
  • Skills run on Jibo's Node 6, so test on a real robot. Set the lowest 5x1 version it works with in supported.
  • Voice-only skills should not add menu buttons.
  • Name and describe it honestly. No copying another listing's name, icon or banner.

Content and rights

  • Keep it friendly for everyone in the home: no hateful, sexual, violent or harassing content.
  • You must have the right to share every image, sound, song and font you include. Note third-party licences in the repository.
  • Don't pretend to be Jibo Inc., 5x1, the Jibo Revival Group or anyone else.

Removal

We may remove a listing that breaks these guidelines, stops working or is abandoned. If there is time we will open an issue first. Things installed from other storefronts or ZIP files are not reviewed by us.
